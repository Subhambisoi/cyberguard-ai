\# Dataset Source



The phishing email dataset used in CYBERGUARD is derived from:



Cyber Cop — Phishing Email Detection



Original source:

https://www.kaggle.com/datasets/subhajournal/phishingemails/data



The project uses a balanced 1,000-sample subset:

\- 500 phishing emails

\- 500 safe emails

\- 0 duplicate records



The 1,000 samples were selected from the balanced 6,000-row subset:

jhonrayo99/phishing-email-balanced-6000



Hugging Face source:

https://huggingface.co/datasets/jhonrayo99/phishing-email-balanced-6000



The Hugging Face dataset documentation identifies itself as a

derived subset of Cyber Cop's original Kaggle dataset.
